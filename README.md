# URL Shortener Service

I'm building a URL Shortener Service using Java and Spring Boot as part of my backend development learning.

The main purpose of this project is to convert long URLs into short links that can be used to access the original URLs. While building it, I'm learning how REST APIs work and how to manage data using a database.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Maven

## Features

- Generate short links for long URLs.
- Store URL details in the database.
- Retrieve the original URL using a short link.
- Redirect users to the original URL.
- Manage URL data through REST APIs.

## How It Works

1. The user sends a long URL through an API request.
2. The application generates a short link.
3. The URL details are stored in the database.
4. When someone accesses the short link, the application finds the original URL and redirects the user to it.
